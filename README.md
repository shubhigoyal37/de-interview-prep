# de-interview-prep

My SQL and Python interview-practice solutions, one file per problem.

## Layout

```
templates/        starter headers for new solutions
  leetcode.sql
  leetcode.py
sql/
  leetcode/       LeetCode database problems (MySQL)
  datalemur/
  stratascratch/
python/
  leetcode/
  hackerrank/
  exercism/
pattern-cards.md  patterns and traps worth remembering
```

## Naming

`<4-digit number>-<kebab-case-title>.<ext>`, e.g. `0178-rank-scores.sql`.
Platforms without problem numbers use the kebab-case title only.
